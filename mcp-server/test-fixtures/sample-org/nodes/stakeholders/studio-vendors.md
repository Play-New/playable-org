# Studio vendors

Production-only vendor partners: web development shops, illustrators, photographers, type foundries, printers. The studio works through this vendor partner network rather than carrying production capability in-house — production-only work stays vendor relationships (outline-charter-2024 §11).

Total 2025 spend €0.6M: web development (€0.3M), illustrators and photographers (€0.15M), type-foundry licensing (€0.05M), printers (€0.07M), other (€0.03M). All paid within 30 days per the studio's commitment (outline-annual-review-2025, outline-charter-2024 §18).
