# UI design

Senior product designers own UI design for individual engagements: screens, components, interactions, prototyping, accessibility audits, pairing with the client's front-end developers (outline-roles-2025).

The product lead reviews every UI deliverable; on enterprise engagements the lead or a senior typically embeds with the client product team for the duration (outline-roles-2025, outline-charter-2024 §16).
