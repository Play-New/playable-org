# Identity system build

Senior designers run the identity-system build for individual engagements: typography, colour, grid, motion logic, illustration direction, photo direction. They typically own one engagement at a time (outline-roles-2025).

Mid-level designers support the senior on the system build. The design lead reviews every deliverable before it leaves the studio per the senior-eyes-on-every-output rule (outline-roles-2025, outline-charter-2024 §9).
