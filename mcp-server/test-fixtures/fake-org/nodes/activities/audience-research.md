# Audience research

The strategy lead and one strategist run the audience-research interviews for an engagement. They transcribe and synthesise into an insights document that feeds [brand positioning](brand-positioning.md) (outline-roles-2025).

The four mid-level strategists run interviews and transcripts on assigned engagements; each strategist runs roughly four engagements per year, in parallel rather than serial (outline-roles-2025).
