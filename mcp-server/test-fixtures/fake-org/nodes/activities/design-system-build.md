# Design system build

Mid-level product designers own design-system documentation when the client is building a system the studio will hand off. The senior product designer leads the system architecture; the mid-level produces the documentation that lets the client team maintain it (outline-roles-2025).

The system build feeds the [asset handover](asset-handover.md) ritual at the end of the engagement.
