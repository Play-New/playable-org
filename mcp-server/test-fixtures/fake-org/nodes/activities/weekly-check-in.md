# Weekly check-in

Account managers run the weekly check-ins on three assigned engagements each. The lead [Tomás Reis](../people/tomas-reis.md) does not run weekly check-ins himself but reviews the notes and intervenes when an engagement is sliding (outline-roles-2025).

The weekly check-in is the rhythm of an Outline engagement; it's where scope drifts get caught, where client approvals get chased, and where the discipline lead is pulled in if the work needs adjustment (outline-roles-2025).
